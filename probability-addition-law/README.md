# Probability – Addition law and independent events

14 English slides in the BeamerRed layout of the existing presentations.

Open index.html in any modern browser, including offline. Arrow keys reveal steps and advance slides. O opens the overview, F toggles full screen.

Content: compound events, the addition law (Example 13), mutually exclusive events, Exercise 1; independent events (coin and die, product rule), mutually exclusive vs. independent, dependent events (drawing without replacement), Exercises 2 and 3; practice: Exercise 11F 1, 4, 5.

Answers: Ex. 1: 0.25, 0.4, not mutually exclusive. Ex. 2: independent. Ex. 3: 0.42, 0.88, 0.12.

The slides are generated with `python3 build.py` (reads the CSS and fonts from ../probability/index.html).

Source: Mathematics Core Topics HL, Chapter 11, sections F and G, pages 265–267.
